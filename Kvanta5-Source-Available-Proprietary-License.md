### Kvanta5 P2QR Transaction System Components

- native Kvanta5 P2QR transaction outputs;
- Kvanta5 P2QR redeem scripts;
- P2SH-wrapped P2QR compatibility outputs;
- Kvanta5 P2QR signature-hash construction;
- ML-DSA-87 P2QR spend verification;

- wallet address handling for P2QR outputs;
- GUI pages, controls, dialogs, labels, and workflows related to P2QR;
- documentation, diagrams, tests, examples, and related source code for the
  Kvanta5 P2QR system.

The P2QR covered components include original Kvanta5 transaction-system code
such as P2QR sighash construction, P2QR output handling, P2SH-wrapped P2QR
compatibility handling, ML-DSA-87 spend validation, and P2QR multisig validation.
